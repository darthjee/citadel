Write the two UI files, from §10, mapped onto Citadel's existing frontend files.

`ui/user.md` (implemented by #5), §10.1–10.4:

- `AuthEvents.emit(loggedIn, isAdmin, pending)` (`frontend/assets/js/client/AuthEvents.js`); new
  `AuthStatus.refresh(client)`; header mount-time check (`components/common/header/`,
  `useAuthEffect.js`) and re-check after login (`LoginModalController.js`) / register
  (`RegisterController.js`).

  anonymous answers drop it.
- Awaiting-approval view (`components/common/awaitingApproval/`): gate, page texts, Check again /
  Log out, re-check on window focus, no timer polling; several tabs each re-check on focus.
- Denied login message on `USER_DENIED` in the login modal.
- Reference + Required tests (AuthStatus, awaiting-approval components, login modal specs).

  helper): status filter, status column, Approve on pending only, Deny behind `window.confirm`,
  no action the API would refuse, `422` messages shown, row replaced with the returned user.
- Reference + Required tests (AdminClient, AdminUsers page / controller / helper, buttons).
